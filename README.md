# swamp-extensions

[Swamp](https://github.com/swamp-club/swamp) extensions published under the
`@randybias` collective.

| Extension | What it manages |
|---|---|
| [`@randybias/cherry-servers`](cherry-servers/) | Cherry Servers servers, projects, SSH keys and plans |

## Install

    swamp extension pull @randybias/<name>

## Working here

Each extension is a standalone directory. `scripts/gates.sh <dir>` runs every
gate; `CONVENTIONS.md` has the rules.
